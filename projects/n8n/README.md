# n8n Workflows

Automation workflows built with [n8n](https://n8n.io/) — an open-source workflow automation tool.

---

## What is n8n?

n8n is a no-code/low-code automation platform. You build workflows by connecting nodes:

- **Triggers** — Start the workflow (form submission, webhook, schedule)
- **Actions** — Do something (append to sheet, send email, call API)
- **Logic** — Make decisions (if/else, switch, merge)
